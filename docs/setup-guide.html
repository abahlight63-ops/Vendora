3 · 🔑 Every key, step by step

❌ MISSING (17) fill in impact order · ✅ YOU HAVE IT (48) collapsed at the bottom · OPTIONAL skippable without shame.

ADMIN_PASSWORD ❌ MISSING · 2 min · unlocks /admin

No website gives this — invent a long random string yourself (password manager). Puts the private admin console behind YOUR password. Set in local .env AND Render → Variables. Without it, /admin stays locked.

FLW_SECRET_KEY · FLW_SECRET_HASH USD CHECKOUT · Naira uses Paystack

Flutterwave (USD / international cards): Dashboard → Settings → API keys → SECRET key (FLWSECK_TEST… to test, live for real money), then Settings → Webhooks → https://YOUR-BACKEND/webhook/flutterwave → copy the secret hash. Bank transfer is retired — card only.

PUBLIC_BASE_URL · FRONTEND_URL ❌ MISSING locally = correct · REQUIRED on Render

Leave empty locally (same-origin mode). On Render set: PUBLIC_BASE_URL=https://vendora-fsse.onrender.com and FRONTEND_URL=https://vendorabot.vercel.app. Without these, cross-site cookies + Paystack callback break in production.

TELEGRAM_WEBHOOK_SECRET · TELEGRAM_SHARED_BOT_TOKEN · TELEGRAM_SHARED_BOT_NAME OPTIONAL · Telegram channel only
  1. Telegram → chat with @BotFather → /newbot → name it → copy the token → TELEGRAM_SHARED_BOT_TOKEN, username → TELEGRAM_SHARED_BOT_NAME. Free.
  2. Invent a random string → TELEGRAM_WEBHOOK_SECRET (same value goes in every BotFather setWebhook … secret_token call).
  3. Skip all three = Telegram stays off, WhatsApp unaffected.
TOKENROUTER_API_KEY · SAMBANOVA_API_KEY · OPENAI_API_KEY OPTIONAL · extra AI brains

Backup AIs only (Gemini + Groq already cover you free). TokenRouter: your TokenRouter dashboard → API Keys (free key → TOKENROUTER_API_KEY, model names → TOKENROUTER_MODEL / TOKENROUTER_MODEL_2). SambaNova: cloud.sambanova.ai → API Keys (free). Pollinations needs no key and is always on. OpenAI: platform.openai.com → API keys (paid, cheapest gpt-4o-mini).

ADS_SCRIPT_URL(2) · SPONSOR_* OPTIONAL · ad money

Networks: Monetag (monetag.com → Sites → MultiTag zone → tag URL) and optional Adsterra Social Bar. Direct sponsor (best ₦): set SPONSOR_TITLE + TEXT + LINK + IMAGE + RATE for one local business; clicks logged, invoice via GET /api/ads/stats + admin key. Full playbook in Section 6.

4 · 🚀 Deploy (backend → web → site)

Env mirror: local .env never uploads — re-type each var on the host.

  1. Render (backend): Blueprint from render.yaml → add secrets (Section 3) → set PUBLIC_BASE_URL → one-off node scripts/schema.js → /health → {"status":"ok"}.
  2. Vercel (web): imports repo, npm run build → dist/. Optional VITE_API_URL override; default proxy already targets Render. Redeploy after env changes.
  3. Netlify (site): same repo → base website, publish website, no build command. Set WEBSITE_URL in Landing.jsx once live to show “Full website ↗”.
  4. Callbacks after every move: Meta webhook → /webhook/whatsapp · Paystack → /webhook/paystack · Telegram setWebhook · Google authorized origins.

5 · 💬 WhatsApp go-live

Embedded Signup (one tap) → TEST → LIVE.

  1. developers.facebook.com → App (Business) → WhatsApp → Embedded Signup config → copy App ID + Configuration ID → META_APP_ID / META_CONFIGURATION_ID (+ server-only META_APP_SECRET).
  2. Owners tap “Connect WhatsApp” in the app (popup stores WABA credentials automatically) → paste webhook URL + verify code in Meta → TEST → LIVE.
  3. Expose server (ngrok http 3000 locally, or Render URL) → paste https://<host>/webhook/whatsapp + verify code in Meta → Configuration → Verify.
  4. /admin → business whatsapp_number must match EXACTLY (incl. whatsapp:) + 3–5 FAQs.
  5. Phone → shop number: “What are your prices?” → AI answers from catalog (check conversations row).
  6. Live: owner connects their real business number through the same popup. Done.

8 · ▶ Play Store (when you have $25)

Two routes — Flutter native (real app) is ready; TWA wrapper is the fallback.

  1. Flutter (recommended — built ✅): cd mobile → flutter pub get → flutter run (live backend by default). flutter build appbundle --dart-define API_BASE_URL=https://vendora-fsse.onrender.com → .aab.
  2. Pay $25 → play.google.com/console → verify → Create app → upload .aab (package com.velosalesai.app).
  3. Listing: name VeloSales Ai, Business category, 1080×1920 screenshots (use the site's chat demo!), 1024×500 feature graphic, privacy URL vendorabot.vercel.app/privacy.
  4. Rating + audience questionnaires → internal test track → production. Back up the signing keystore — losing it = never update again.
  5. TWA fallback: manifest + assetlinks.json already ship in dist/ → PWABuilder → replace REPLACE_WITH_PLAY_SIGNING_SHA256 → push.
